# 밸런싱 데이터 파이프라인

게임의 모든 밸런싱 수치(전투/보상/스탯/장비/숙련/존재력트리/타임하이스트/오프라인)는
`balance/balance.xlsx` 한 파일에서 관리합니다. 코드를 건드리지 않고 엑셀만 고쳐서
게임 밸런스를 조정할 수 있습니다.

## 시트 구조

각 시트는 색으로 구분되는 제목 캡션(1행) + **이름 붙은 엑셀 표(Table)**(2행부터)로
구성됩니다. 표에는 필터 버튼과 줄무늬 서식이 자동으로 붙어 있고, 값을 고치는 열(D열)은
연노랑, 건드리면 안 되는 열(C열)은 회색으로 미리 칠해뒀습니다.

| 행 | 내용 |
|---|---|
| 1행 | 시트 제목 캡션 (시트마다 다른 색. 표에는 포함 안 됨, 순수 시각 구분용) |
| 2행 | 표 헤더 (번호 / 이름 / key / value / 기본값 / 설명) |
| 3행부터 | 실제 데이터 |

표 이름은 시트별로 다음과 같이 붙어 있습니다 (엑셀 좌상단 "이름 상자"에 표 이름을
입력하면 바로 그 표로 이동합니다):

| 시트 | 표 이름 |
|---|---|
| 전투 | `tbl_battle` |
| 보상 | `tbl_rewards` |
| 스탯 | `tbl_stats` |
| 장비숙련 | `tbl_equipmentMastery` |
| 존재력트리 | `tbl_existTree` |
| 타임하이스트 | `tbl_timeHeist` |
| 오프라인 | `tbl_offline` |

데이터 열:

| 열 | 이름 | 색 | 설명 |
|---|---|---|---|
| A | 번호 | - | 참고용 일련번호. 순서 바뀌어도 무방 |
| B | 이름 | - | 짧은 한글 이름. 참고용 |
| C | **key** | 회색 | **코드가 참조하는 식별자. 절대 수정 금지** |
| D | **value** | 연노랑 | **실제로 수정하는 값. 여기만 고치면 됩니다** |
| E | 기본값 | - | 최초 생성 시점 값. 되돌릴 때 참고 |
| F | 설명 | - | 값의 의미, 관련 공식 |

## 수정 절차

1. `balance/balance.xlsx`를 엑셀(또는 호환 프로그램)로 엽니다.
2. 바꾸고 싶은 시트를 고르고, **연노랑으로 칠해진 D열(value)만** 원하는 값으로 수정합니다.
3. 저장하고 **엑셀 프로그램을 완전히 닫습니다.**
   (엑셀이 파일을 잠그고 있으면 다음 단계에서 읽기에 실패합니다.)
4. 터미널에서 실행합니다.
   ```bash
   npm run balance
   ```
5. 콘솔에 찍히는 결과를 확인합니다.
   - 몇 개 항목을 읽었는지
   - 이전 값과 달라진 항목이 있으면 `카테고리.key: 이전값 → 새값` 형태로 목록 출력
   - 만약 값이 숫자가 아니거나 key가 중복되면 **어느 시트, 몇 번째 행**인지 정확히 알려주고
     `src/data/balance.json`은 갱신되지 않은 채(에러) 중단됩니다. 엑셀에서 해당 위치를 고친 뒤
     다시 `npm run balance`를 실행하세요.
6. `npm run dev`로 게임을 켜서 원하는 대로 반영됐는지 확인합니다.
7. 문제 없으면 `balance/balance.xlsx`와 갱신된 `src/data/balance.json`을 함께 커밋합니다.

## 주의사항

- **C열(key, 회색)은 절대 수정하지 마세요.** 코드가 이 문자열로 값을 찾아 읽습니다.
  C열 값을 바꾸면 그 항목은 "새 키"로 취급되어 기존 값이 사라진 것처럼 동작합니다
  (실제로는 `src/data/balance.ts`의 기본값으로 조용히 대체됩니다 — 게임이 죽지는 않지만
  의도한 값이 반영되지 않습니다).
- **1~2행(제목/표 헤더)과 행 순서를 건드리지 마세요.** `scripts/build-balance.mjs`는 항상
  3행부터를 데이터로 읽습니다.
- **행을 새로 추가/삭제하지 마세요.** 값을 안 쓰고 싶으면 기본값(E열)과 같은 값으로 되돌려두는
  것을 권장합니다. 코드가 참조하는 key 자체를 지우면 해당 항목은 기본값으로 대체됩니다.
- **시트 이름·표 이름도 바꾸지 마세요.** (시트: 전투 / 보상 / 스탯 / 장비숙련 / 존재력트리 /
  타임하이스트 / 오프라인) `scripts/build-balance.mjs`가 이 시트 이름으로 찾습니다
  (표 이름 `tbl_*` 자체는 코드가 안 읽지만, 헷갈리지 않게 유지하는 걸 권장합니다).
- `npm run balance`를 실행하기 전에 **엑셀 파일을 꼭 닫아주세요.** 열려 있으면
  "파일을 열 수 없습니다" 에러가 납니다.
- A(번호)/B(이름)/E(기본값)/F(설명) 열은 참고용입니다. 자유롭게 메모를 남겨도 되고,
  E열을 보고 원래 값으로 되돌릴 수 있습니다. 게임 동작에는 영향을 주지 않습니다.
- `src/data/balance.json`은 `balance.xlsx`로부터 자동 생성되는 빌드 산출물입니다.
  이 파일을 직접 수정하지 말고, 항상 엑셀 → `npm run balance`를 거치세요.
  (git에는 xlsx와 json을 둘 다 커밋합니다 — json이 있어야 앱이 바로 실행됩니다.)

## 파일 구성

- `balance/balance.xlsx` — 사람이 수정하는 원본. 시트 7개, 시트당 제목 캡션 + 이름 붙은
  표(번호 / 이름 / key / value / 기본값 / 설명 6열)
- `scripts/build-balance.mjs` — `balance.xlsx` → `src/data/balance.json` 변환 스크립트
  (`npm run balance`). ExcelJS로 읽습니다.
- `scripts/generate-balance-xlsx.mjs` — `balance.xlsx`가 없을 때(또는 `--force`로 초기값으로
  완전히 되돌리고 싶을 때) 처음부터 다시 만드는 스크립트. 평소에는 쓸 일이 없습니다.
- `src/data/balance.json` — 빌드 산출물. 게임이 실제로 읽는 파일.
- `src/data/balance.ts` — `balance.json`을 타입이 붙은 `BALANCE` 객체로 내보냄.
  json에 특정 key가 없으면 코드에 내장된 기본값으로 자동 대체됩니다.
