# 밸런싱 데이터 파이프라인

게임의 모든 밸런싱 수치(전투/보상/스탯/장비/숙련/존재력트리/타임하이스트/오프라인)는
`balance/balance.xlsx` 한 파일에서 관리합니다. 코드를 건드리지 않고 엑셀만 고쳐서
게임 밸런스를 조정할 수 있습니다.

## 수정 절차

1. `balance/balance.xlsx`를 엑셀(또는 호환 프로그램)로 엽니다.
2. 바꾸고 싶은 시트를 고르고, **B열(value)만** 원하는 값으로 수정합니다.
3. 저장하고 **엑셀 프로그램을 완전히 닫습니다.**
   (엑셀이 파일을 잠그고 있으면 다음 단계에서 읽기에 실패합니다.)
4. 터미널에서 실행합니다.
   ```bash
   npm run balance
   ```
5. 콘솔에 찍히는 결과를 확인합니다.
   - 몇 개 항목을 읽었는지
   - 이전 값과 달라진 항목이 있으면 `카테고리.key: 이전값 → 새값` 형태로 목록 출력
   - 만약 값이 숫자가 아니거나 key가 중복되면 **어느 시트, 몇 번째 행**인지 정확히 알려주고
     `src/data/balance.json`은 갱신되지 않은 채(에러) 중단됩니다. 엑셀에서 해당 위치를 고친 뒤
     다시 `npm run balance`를 실행하세요.
6. `npm run dev`로 게임을 켜서 원하는 대로 반영됐는지 확인합니다.
7. 문제 없으면 `balance/balance.xlsx`와 갱신된 `src/data/balance.json`을 함께 커밋합니다.

## 주의사항

- **A열(key)은 절대 수정하지 마세요.** 코드가 이 문자열로 값을 찾아 읽습니다.
  A열 값을 바꾸면 그 항목은 "새 키"로 취급되어 기존 값이 사라진 것처럼 동작합니다
  (실제로는 `src/data/balance.ts`의 기본값으로 조용히 대체됩니다 — 게임이 죽지는 않지만
  의도한 값이 반영되지 않습니다).
- **행을 새로 추가/삭제하지 마세요.** 값을 안 쓰고 싶으면 기본값(D열)과 같은 값으로 되돌려두는
  것을 권장합니다. 코드가 참조하는 key 자체를 지우면 해당 항목은 기본값으로 대체됩니다.
- **시트 이름도 바꾸지 마세요.** (전투 / 보상 / 스탯 / 장비숙련 / 존재력트리 / 타임하이스트 / 오프라인)
  `scripts/build-balance.mjs`가 이 이름으로 시트를 찾습니다.
- `npm run balance`를 실행하기 전에 **엑셀 파일을 꼭 닫아주세요.** 열려 있으면
  "파일을 열 수 없습니다" 에러가 납니다.
- C열(설명)과 D열(기본값)은 참고용입니다. 자유롭게 메모를 남겨도 되고, D열을 보고
  원래 값으로 되돌릴 수 있습니다. 둘 다 게임 동작에는 영향을 주지 않습니다.
- `src/data/balance.json`은 `balance.xlsx`로부터 자동 생성되는 빌드 산출물입니다.
  이 파일을 직접 수정하지 말고, 항상 엑셀 → `npm run balance`를 거치세요.
  (git에는 xlsx와 json을 둘 다 커밋합니다 — json이 있어야 앱이 바로 실행됩니다.)

## 파일 구성

- `balance/balance.xlsx` — 사람이 수정하는 원본. 시트 7개, 시트당 A~D열
  (key / value / 설명 / 기본값)
- `scripts/build-balance.mjs` — `balance.xlsx` → `src/data/balance.json` 변환 스크립트
  (`npm run balance`)
- `scripts/generate-balance-xlsx.mjs` — `balance.xlsx`가 없을 때(또는 `--force`로 초기값으로
  완전히 되돌리고 싶을 때) 처음부터 다시 만드는 스크립트. 평소에는 쓸 일이 없습니다.
- `src/data/balance.json` — 빌드 산출물. 게임이 실제로 읽는 파일.
- `src/data/balance.ts` — `balance.json`을 타입이 붙은 `BALANCE` 객체로 내보냄.
  json에 특정 key가 없으면 코드에 내장된 기본값으로 자동 대체됩니다.
